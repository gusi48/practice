# Система обработки кадровой документации (WinForms MDI Application)

Программный комплекс для управления, анализа и редактирования кадровых текстовых документов, разработанный в среде **Visual Studio** на языке **C#**. Проект спроектирован с использованием многослойной архитектуры, ролевой модели безопасности и ключевых паттернов проектирования (GoF).

## 🚀 Основной функционал

* **Многодокументный интерфейс (MDI):** Одновременная изолированная работа с несколькими документами в рамках одного главного окна.
* **Архитектура MVC & SOLID:** Четкое разделение ответственности между графическим интерфейсом, контроллерами и бизнес-логикой.
* **Система безопасности (RBAC):** Разграничение прав доступа (Администратор / Пользователь) с динамической блокировкой интерфейса.
* **Аналитический модуль:** Автоматический подсчет символов, слов и строк в реальном времени с использованием привязки данных (`BindingList`).
* **Фоновые процессы:** Автоматическое резервное копирование данных по таймеру.

---

## 🛠 Реализованные паттерны проектирования

1.  **Memento (Мементо):** Управление историей изменений текста, обеспечивающее глубокий функционал отмены и повтора операций (`Undo` / `Redo`).
2.  **Observer (Наблюдатель):** Событийно-ориентированная подписка главного окна на изменения в документах для мгновенного обновления статистики.
3.  **Strategy (Стратегия):** Инкапсуляция алгоритмов обработки и форматирования кадровых данных, позволяющая менять логику на лету.
4.  **Factory Method (Фабричный метод):** Централизованная генерация структурированных отчетов без жесткой привязки к конкретным классам выгрузки.

## 📂 Структура проекта в Visual Studio

* **📂 Controllers**
    * `DocumentController.cs` — Управляющая логика, связывающая интерфейс, модель данных и сервисы.
* **📂 Models**
    * `DocumentModel.cs` — Слой данных, содержащий структуру, поля и свойства кадрового документа.
* **📂 Patterns**
    * `DocumentMemento.cs` — Реализация паттерна **Memento** (хранение снимков состояний текста для Undo/Redo).
    * `ReportFactory.cs` — Реализация паттерна **Factory Method** (инкапсуляция логики генерации отчетов).
    * `TextStrategy.cs` — Реализация паттерна **Strategy** (интерфейс и алгоритмы обработки текстовых данных).
* **📂 Services**
    * `AutosaveService.cs` — Фоновый сервис автоматического сохранения документов по таймеру.
* **📂 Views**
    * `DocumentChildForm.cs` — Дочернее окно текстового редактора (внутри MDI-контейнера).
    * `LoginForm.cs` — Форма авторизации пользователей для разграничения доступа к системе.
* `Form1.cs` — Главная родительская форма (основа MDI-интерфейса, меню, статус-бар и логика подписки **Observer**).
* `Program.cs` — Точка входа в приложение.
* **📂 Tests** (Проект автоматизированного тестирования)
    * `UnitTest1.cs` — Набор модульных тестов для проверки корректности алгоритмов.
